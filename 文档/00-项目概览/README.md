# NoteMind — 基于 RAG 的智能知识管理平台设计与实现

> 本科毕业设计 · 江西师范大学 · 软件工程专业

## 项目简介

一个融合 Obsidian 知识管理能力与 RAG 文档智能能力的 AI 知识管理平台。

**核心理念**：
- **笔记**负责知识创造和沉淀
- **知识库**负责知识理解和检索
- **AI**负责辅助整理、分析、生成

系统不是简单的 Markdown 编辑器，也不是单纯的聊天机器人，而是一个结合知识管理（PKM）、Markdown 笔记、文档智能解析、RAG 知识库、LLM AI 辅助的综合平台。

## 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Spring Boot 3 + Spring AI + MyBatis-Plus + **Spring Security + JWT** + Java 17 |
| 前端 | Vue 3 + **TypeScript** + Vite + Tailwind CSS + shadcn-vue + Vditor |
| 数据库 | PostgreSQL 16 + pgvector + Redis |
| 对象存储 | MinIO |
| AI 接入 | DeepSeek / OpenAI / Gemini（多供应商，Spring AI 统一抽象） |
| 通信 | SSE（流式输出） |
| 部署 | Docker Compose + Nginx |

## 系统模块

```
系统
├── AI助手      — 通用 AI 对话 + 可选知识库绑定 + 用户画像
├── 笔记        — 多仓库 Markdown 笔记 + 三栏布局 + AI 辅助
├── 知识库      — 文档上传(多格式) → RAG 智能问答 + 引用溯源
├── 用户中心    — 注册 / 登录 / 个人信息管理
└── 设置        — AI 模型管理 + Prompt 快捷指令 + 基础设置
```

## 核心功能

| 模块 | 功能 |
|------|------|
| AI助手 | 新建对话、历史管理、收藏、知识库绑定、AI 记忆 |
| 笔记系统 | 多仓库、Markdown 编辑、AI 辅助写作、选中文字操作、AI 直接修改、文件导入、知识图谱 |
| 知识库 | 文档管理（MD/PDF/Word/PPT/图片）、RAG 问答、引用溯源、文档详情 |
| 用户中心 | 注册、登录、JWT 认证、个人信息管理、修改密码 |
| 设置 | 主题、AI 模型管理、API Key 配置、温度/TopK 参数、Prompt 快捷指令 |
