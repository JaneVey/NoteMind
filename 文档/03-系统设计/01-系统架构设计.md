# 系统架构设计文档

> 毕业设计：基于 RAG 的 NoteMind 智能知识管理平台
> 版本：v0.3
> 最后更新：2026-10-07

> **范围约束**：本文档描述的系统**不包含 AI Agent（工具调用循环）与多 Agent 编排**。
> AI 能力边界由 [[范围决策书]] 定义，两者冲突时以该文档为准。
> 本文档不涉及"思考链路"（`reasoning_content`）展示，该能力属 L3，设计见 [[范围决策书]] 第五节。

---

## 1. 项目定位

一个**单人使用**的 Web 端 AI 知识管理平台，融合 Obsidian 的 Markdown 笔记体验与 RAG 知识库能力。

**核心理念**：
- **笔记**负责知识创造和沉淀
- **知识库**负责知识理解和检索
- **AI**负责辅助整理、分析、生成

**五大模块**：

```
系统
├── AI助手      — 类似 ChatGPT 首页的通用 AI 对话入口
├── 笔记        — 多仓库 Markdown 笔记（三栏布局 + AI 辅助）
├── 知识库      — 独立文档管理 → RAG 智能问答
├── 用户中心    — 注册 / 登录 / JWT 鉴权 / 个人信息
└── 设置        — AI 模型 + Prompt 快捷指令 + 系统配置
```

### 4.1 AI 助手模块

**定位**：类似 ChatGPT 首页，提供不依赖笔记、不依赖知识库的通用 AI 对话入口。

**页面布局**：

```
│  📌 Java学习     │  │  消息气泡（AI）            │   │
│  📌 毕设讨论     │  │  引用来源 [Spring.pdf 3章] │   │
│  Spring问题      │  └──────────────────────────┘   │
│  AI入门          │  ┌──────────────────────────┐   │
│                  │  │  输入框                    │   │
```

**定位**：类似 ima 个人知识库，上传资料 → 构建 RAG → AI 智能问答。

**结构**：

```
知识库

├── 毕设资料库
└── 论文库
```

**文档上传页面**：
```
┌─────────────────────────────────────────┐
│  ┌─── 拖拽上传区域 ─────────────────┐   │
│  │  拖拽文件到此处，或点击上传        │   │
│  │  支持 Markdown / PDF / Word / PPT  │   │
│  │  图片                            │   │
│  └────────────────────────────────────┘   │
│                                           │
│  文件列表：                                │
│  ┌────────────────────────────────────┐  │
│  │ Java.pdf    2.3MB  ✅ 解析完成    │  │
│  │ Spring.md   1.1MB  ✅ 解析完成    │  │
│  │ 论文.docx   5.2MB  🔄 解析中     │  │
│  │ 架构图.png  0.8MB  ❌ 解析失败    │  │
│  └────────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

**文档处理流程**：
```
上传
  ↓
MinIO 存储
  ↓
结构解析 (Apache Tika)
  ↓
文本清洗（去除无关内容、格式化）
  ↓
OCR（图片/PDF 扫描件）—— P1 阶段
  ↓
文本切片（按段落/标题分块 + 块重叠）
  ↓
Embedding（调用供应商 API）
  ↓
向量数据库（pgvector）
  ↓
完成（状态更新）
```


### 4.5 用户中心模块

**定位**：提供注册、登录、个人信息管理等用户体系功能，所有业务模块通过 `user_id` 关联。

**功能列表**：

| 功能 | 说明 |
|------|------|
| 注册 | 用户名 + 密码 + 邮箱 |
| 登录 | 验证密码，签发 JWT Token |
| 修改密码 | 旧密码验证 → BCrypt 更新 |
| 修改个人信息 | 昵称、头像 |
| 忘记密码 | ⚠️ 可选 |

**后端设计**：

```
auth/
  controller/AuthController.java     — 登录/注册
  service/AuthService.java           — 认证逻辑
  util/JwtUtils.java                 — JWT 签发与验证

user/
  controller/UserController.java     — 用户信息 CRUD
  service/UserService.java           — 用户管理

framework/security/
  SecurityConfig.java                — Spring Security 配置
  JwtAuthenticationFilter.java       — JWT 过滤器
  LoginUser.java                     — 当前登录用户上下文
```

**架构原则**：

```
Controller 层：
    Long userId = LoginUser.getId();     ← 从 Security 上下文获取

Service 层：
    noteService.getUserNotes(userId);   ← 只传 userId，不感知 Security
    knowledgeService.listByUserId(userId);
    
业务模块：
    不知道 JWT、不知道登录、不知道 Security
    只知道"当前有一个 userId"
```

**前端相关**：

```
views/Login.vue         — 登录页
views/Register.vue      — 注册页
api/auth.js             — 登录/注册 API
stores/authStore.js     — 认证状态（Token、用户信息）
router/guard.js         — 路由守卫（未登录跳转登录页）
utils/request.js        — Axios 拦截器（自动携带 Token、401 拦截）
```

## 5. 笔记与知识库关系

**设计原则**：单向联动。

### 笔记 → 知识库

```
选择 Java 文件夹
  ↓
点击 "加入知识库"
  ↓
笔记内容 → 分块 → Embedding → 知识库 RAG 数据
```

### 知识库 → 笔记

暂不做。知识库主要用于理解和检索，笔记用于创造和沉淀。

## 9. 安全设计

### 9.1 认证流程（JWT）

```
用户注册 / 登录
    │
    ▼
AuthController.login()
    │
    ├── 验证用户名密码（BCrypt 比对）
    ├── 生成 JWT Token（含 userId、过期时间）
    └── 返回 Token 给前端

后续请求：
    前端 Header: Authorization: Bearer <token>
    │
    ▼
JwtAuthenticationFilter（Spring Security Filter）
    ├── 解析 Token → 获取 userId
    ├── 构建 Authentication 对象 → SecurityContextHolder
    └── 放行到 Controller
    │
    ▼
Controller: Long userId = LoginUser.getId();
Service: 只通过 userId 操作数据
```

### 9.2 Spring Security 配置

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) {
        http
            .csrf(csrf -> csrf.disable())
            .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()         // 登录注册开放
                .requestMatchers("/api/health").permitAll()          // 健康检查开放
                .anyRequest().authenticated()                        // 其他接口需登录
            )
            .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);
        return http.build();
    }
}
```

### 9.3 安全措施

| 措施 | 说明 |
|------|------|
| **JWT 鉴权** | 登录后颁发 Token，请求头携带 |
| **BCrypt 加密** | 用户密码不可逆加密存储 |
| **API Key 加密** | AI 供应商 Key 在数据库中 AES 加密 |
| **请求限流** | AI 接口限流，防止刷爆额度 |
| **MinIO 访问控制** | 临时签名 URL，防止越权访问 |
| **XSS 防护** | Markdown 渲染时过滤 XSS |
| **用户数据隔离** | 所有业务表通过 `user_id` 隔离，天然多租户 |
