# 数据库设计文档

> 项目：基于 RAG 的 NoteMind 智能知识管理平台
> 数据库：PostgreSQL 16 + pgvector
> 版本：v0.2（重构后更新）
> 最后更新：2026-07-20

---

## 1. 数据库概览

### 1.1 命名规范

| 规则 | 示例 |
|------|------|
| 表名：小写蛇形 + 复数 | `notes`, `knowledge_chunks` |
| 主键：`id`（自增 BIGSERIAL） | `id BIGSERIAL PRIMARY KEY` |
| 外键：`{关联表}_id` | `notebook_id`, `knowledge_base_id` |
| 时间字段：`created_at`, `updated_at` | `TIMESTAMP WITH TIME ZONE` |
| 逻辑删除：`is_deleted` | `BOOLEAN DEFAULT FALSE` |

### 1.2 pgvector 说明

MVP 阶段向量维度使用 **1024 维**。

选定 1024 的理由：开发阶段使用硅基流动（SiliconFlow）的 Embedding 服务，其 `BAAI/bge-m3`（**无限免费**）与 `Qwen3-Embedding-0.6B` 均为 1024 维；阿里云百炼 `text-embedding-v3` 默认维度同样是 1024。**多个可选的免费/低价模型在 1024 维上交汇**，因此 schema 取 1024 可获得最大的模型替换自由度。

> ⚠️ **更换 Embedding 模型会使已有向量全部作废。**
> 若切换到其他维度的模型（如 OpenAI `text-embedding-3-small` 1536 维、百炼 `text-embedding-v4` 可选 1536 维、智谱 `embedding-3` 2048 维），
> 必须同时修改 `VECTOR(1024)` 与 `application.yml` 的 `app.ai.embedding-dimension`，**并重新解析全部文档**。
>
> ⚠️ **DeepSeek 不提供 Embedding 接口**（[DeepSeek-V3 issue #806](https://github.com/deepseek-ai/DeepSeek-V3/issues/806)），
> 因此"对话用 DeepSeek、向量化用其他供应商"是本项目的硬约束。

```sql

```

## 2. 核心表结构

### 2.1 用户表（note_user）

```sql
CREATE TABLE note_user (
    id          BIGSERIAL PRIMARY KEY,
    username    VARCHAR(100) NOT NULL UNIQUE,
    email       VARCHAR(255),
    password    VARCHAR(500) NOT NULL,
    nickname    VARCHAR(100),
    avatar      VARCHAR(500),
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

**说明**：
- `password` 使用 BCrypt 加密
- `avatar` 为 MinIO 头像路径

---

### 2.2 仓库表（notebook）

多仓库设计，类似 Obsidian Vault，不同领域知识隔离。

```sql
CREATE TABLE notebook (
    id          BIGSERIAL PRIMARY KEY,
    user_id     BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    name        VARCHAR(255) NOT NULL,
    description VARCHAR(1000),
    icon        VARCHAR(50) DEFAULT '📒',
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

**说明**：
- `user_id` 关联用户
- 每个仓库独立管理知识图谱
- 仓库之间笔记不互通

---

### 2.2 目录表（folder）

```sql
CREATE TABLE folder (
    id          BIGSERIAL PRIMARY KEY,
    user_id     BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    notebook_id BIGINT NOT NULL REFERENCES notebook(id) ON DELETE CASCADE,
    parent_id   BIGINT REFERENCES folder(id) ON DELETE CASCADE,
    name        VARCHAR(255) NOT NULL,
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    is_deleted  BOOLEAN DEFAULT FALSE
);

CREATE INDEX idx_folder_user_id ON folder(user_id);
CREATE INDEX idx_folder_notebook_id ON folder(notebook_id);
CREATE INDEX idx_folder_parent_id ON folder(parent_id);
```

**说明**：
- `notebook_id` 关联仓库（重构后新增）
- `parent_id` 为 NULL 表示根目录
- 支持多级嵌套，应用层控制最大层级（建议不超过 5 层）
- 删除目录时级联删除子目录

### 2.3 笔记表（note）

```sql
CREATE TABLE note (
    id            BIGSERIAL PRIMARY KEY,
    user_id       BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    notebook_id   BIGINT NOT NULL REFERENCES notebook(id) ON DELETE CASCADE,
    folder_id     BIGINT REFERENCES folder(id) ON DELETE SET NULL,
    title         VARCHAR(500) NOT NULL DEFAULT '未命名笔记',
    content_md    TEXT,                      -- Markdown 原文
    content_html  TEXT,                      -- 渲染后的 HTML（缓存）
    word_count    INTEGER DEFAULT 0,         -- 字数统计
    is_pinned     BOOLEAN DEFAULT FALSE,     -- 置顶
    created_at    TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at    TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    is_deleted    BOOLEAN DEFAULT FALSE
);

CREATE INDEX idx_note_user_id ON note(user_id);
CREATE INDEX idx_note_notebook_id ON note(notebook_id);
CREATE INDEX idx_note_folder_id ON note(folder_id);
CREATE INDEX idx_note_updated_at ON note(updated_at DESC);
CREATE INDEX idx_note_is_deleted ON note(is_deleted);
```

**说明**：
- `notebook_id` 关联仓库（重构后新增，笔记属于某个仓库）
- `content_html` 是渲染后缓存，减少前端渲染压力
- `folder_id` 为 NULL 表示笔记在根目录
- `ON DELETE SET NULL`：删除目录不删笔记，笔记回到根目录

### 2.4 笔记链接表（note_link）

双向链接，用于知识图谱。

```sql
CREATE TABLE note_link (
    id              BIGSERIAL PRIMARY KEY,
    source_note_id  BIGINT NOT NULL REFERENCES note(id) ON DELETE CASCADE,
    target_note_id  BIGINT NOT NULL REFERENCES note(id) ON DELETE CASCADE,
    link_type       VARCHAR(20) DEFAULT 'wikilink',  -- wikilink / ai_auto
    created_at      TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(source_note_id, target_note_id)
);

CREATE INDEX idx_note_link_source ON note_link(source_note_id);
CREATE INDEX idx_note_link_target ON note_link(target_note_id);
```

**说明**：
- 解析 Markdown 中的 `[[note-title]]` 语法
- `link_type`：`wikilink` 为用户手动创建，`ai_auto` 为 AI 自动分析（未来增强）
- UNIQUE 约束防止重复链接
- 知识图谱查询时，可以获取某个节点的所有关联笔记

### 2.6 导入文档表（document_source）

重构后支持多格式文档，与知识库关联，使用 MinIO 存储。

```sql
CREATE TABLE document_source (
    id                BIGSERIAL PRIMARY KEY,
    knowledge_base_id BIGINT NOT NULL REFERENCES knowledge_base(id) ON DELETE CASCADE,
    note_id           BIGINT REFERENCES note(id) ON DELETE SET NULL,  -- 可选关联笔记
    file_name         VARCHAR(500) NOT NULL,       -- 原始文件名
    file_type         VARCHAR(20) NOT NULL,         -- md / pdf / docx / pptx / png / jpg
    file_size         BIGINT NOT NULL,              -- 字节数
    storage_path      VARCHAR(1000),                -- MinIO 存储路径
    raw_content       TEXT,                         -- 提取的纯文本内容
    chunk_status      VARCHAR(20) DEFAULT 'pending', -- pending / processing / done / failed
    error_message     TEXT,                         -- 失败原因
    imported_at       TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_document_knowledge_base ON document_source(knowledge_base_id);
CREATE INDEX idx_document_note_id ON document_source(note_id);
CREATE INDEX idx_document_chunk_status ON document_source(chunk_status);
```

**说明**：
- `knowledge_base_id` 关联知识库（重构后新增，文档属于某个知识库）
- `note_id` 可选关联笔记（笔记加入知识库时关联）
- `storage_path` MinIO 中的存储路径（重构后新增）
- `file_type` 扩展支持更多格式
- `chunk_status` 记录分块 + Embedding 的处理状态

### 2.7 知识块表（knowledge_chunk）

```sql
CREATE TABLE knowledge_chunk (
    id                BIGSERIAL PRIMARY KEY,
    document_id       BIGINT REFERENCES document_source(id) ON DELETE CASCADE,
    knowledge_base_id BIGINT NOT NULL REFERENCES knowledge_base(id) ON DELETE CASCADE,
    note_id           BIGINT REFERENCES note(id) ON DELETE CASCADE,
    chunk_index       INTEGER NOT NULL,              -- 块序号
    chunk_content     TEXT NOT NULL,                 -- 块文本
    chunk_token_count INTEGER DEFAULT 0,             -- 块 Token 数
    embedding         VECTOR(1024),                  -- 向量
    source_info       JSONB,                         -- 来源信息（文档名、页码等）
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_chunk_document_id ON knowledge_chunk(document_id);
CREATE INDEX idx_chunk_knowledge_base ON knowledge_chunk(knowledge_base_id);
CREATE INDEX idx_chunk_note_id ON knowledge_chunk(note_id);
-- 向量索引：开发阶段先不建（见下方说明），数据量上来后再按需创建 HNSW
-- CREATE INDEX idx_chunk_embedding ON knowledge_chunk USING hnsw (embedding vector_cosine_ops);
```

**说明**：
- `knowledge_base_id` 重构后新增，支持按知识库检索
- `embedding` 是 pgvector 的核心字段，类型为 `VECTOR(1024)`
- `source_info` JSONB 存储来源信息，用于引用溯源

**⚠️ 关于向量索引（重要，且是论文可写的技术点）**

**开发阶段不要建向量索引。** 原因：

| 索引 | 问题 |
|------|------|
| `ivfflat`（原方案） | 需要**先有数据再建索引**（它要对数据做聚类）。毕设数据量只有几百到几千行，`lists = 100` 意味着每个簇不到 100 行，**召回率会明显下降** —— 索引反而比顺序扫描更差 |
| `hnsw`（推荐后续启用） | 无需训练、小数据量表现好、召回率高。**数据量上来后（例如 > 1 万块）再建** |

**结论**：几千行的规模，PostgreSQL 顺序扫描（全表扫 + `<=>` 排序）在毫秒级完成，**比带索引还快且结果精确**。等数据量增长后再启用 HNSW，并在论文中记录"索引策略与数据规模的关系"这一实验结论。

### 2.8 AI 供应商配置表（ai_config）

重构后适配 Spring AI，新增 Gemini 支持，增加 user_id 支持多用户。

```sql
CREATE TABLE ai_config (
    id                BIGSERIAL PRIMARY KEY,
    user_id           BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    provider_name     VARCHAR(50) NOT NULL,          -- deepseek / openai / gemini
    display_name      VARCHAR(100),                  -- 显示名称
    api_key           TEXT NOT NULL,                 -- AES 加密存储
    api_base_url      VARCHAR(500),                  -- API 地址
    chat_model        VARCHAR(100) NOT NULL,          -- 对话模型
    embedding_model   VARCHAR(100),                  -- Embedding 模型
    is_active         BOOLEAN DEFAULT FALSE,          -- 当前激活
    sort_order        INTEGER DEFAULT 0,
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(user_id, provider_name)
);
```

**说明**：
- `api_key` 在存入时做 AES 加密，读取时解密
- `is_active` 标记当前正在使用的供应商（同一时间只有一个活跃）
- `api_base_url` 为 NULL 时使用该供应商的官方默认地址
- 重构后：新增 `chat_model` / `embedding_model` 分别配置，新增 Gemini 支持，移除 Claude
- Spring AI 通过 provider_name 确定使用哪个 ChatModel/EmbeddingModel 实现

### 2.9 对话表（conversation）

重构后新增知识库绑定、收藏功能和 user_id。

```sql
CREATE TABLE conversation (
    id                BIGSERIAL PRIMARY KEY,
    user_id           BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    title             VARCHAR(500),                  -- 对话标题
    knowledge_base_id BIGINT REFERENCES knowledge_base(id) ON DELETE SET NULL,  -- 绑定知识库
    provider_name     VARCHAR(50),                   -- 使用的供应商
    model             VARCHAR(100),                  -- 使用的模型
    mode              VARCHAR(20) DEFAULT 'chat',    -- chat / rag
    is_favorite       BOOLEAN DEFAULT FALSE,          -- 收藏
    message_count     INTEGER DEFAULT 0,
    token_usage       INTEGER DEFAULT 0,             -- 累计 Token 消耗
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_conversation_favorite ON conversation(is_favorite);
CREATE INDEX idx_conversation_updated_at ON conversation(updated_at DESC);
```

**说明**：
- `knowledge_base_id` 重构后新增，对话可绑定知识库
- `is_favorite` 重构后新增，收藏功能
- `mode` 区分普通对话和 RAG 模式
- MVP 不涉及用户系统，所以没有 `user_id`

### 2.10 消息表（message）

```sql
CREATE TABLE message (
    id                BIGSERIAL PRIMARY KEY,
```

**说明**：

### 2.11 Prompt 快捷指令表（prompt_shortcut）

## 4. 完整 DDL 脚本

```sql
-- ============================================
-- NoteMind — 基于 RAG 的智能知识管理平台
-- 数据库初始化脚本
-- 数据库：PostgreSQL 16 + pgvector
-- 版本：v0.2（重构后）
-- ============================================

-- 启用 pgvector 扩展
CREATE EXTENSION IF NOT EXISTS vector;

-- ============================================
-- 1. 用户表
-- ============================================
CREATE TABLE note_user (
    id          BIGSERIAL PRIMARY KEY,
    username    VARCHAR(100) NOT NULL UNIQUE,
    email       VARCHAR(255),
    password    VARCHAR(500) NOT NULL,   -- BCrypt 加密
    nickname    VARCHAR(100),
    avatar      VARCHAR(500),            -- MinIO 头像路径
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_note_user_username ON note_user(username);

-- ============================================
-- 2. 仓库表（多仓库设计）
-- ============================================
CREATE TABLE notebook (
    id          BIGSERIAL PRIMARY KEY,
    user_id     BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    name        VARCHAR(255) NOT NULL,
    description VARCHAR(1000),
    icon        VARCHAR(50) DEFAULT '📒',
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_notebook_user_id ON notebook(user_id);

-- ============================================
-- 3. 目录表
-- ============================================
CREATE TABLE folder (
    id          BIGSERIAL PRIMARY KEY,
    user_id     BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    notebook_id BIGINT NOT NULL REFERENCES notebook(id) ON DELETE CASCADE,
    parent_id   BIGINT REFERENCES folder(id) ON DELETE CASCADE,
    name        VARCHAR(255) NOT NULL,
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    is_deleted  BOOLEAN DEFAULT FALSE
);
CREATE INDEX idx_folder_user_id ON folder(user_id);
CREATE INDEX idx_folder_notebook_id ON folder(notebook_id);
CREATE INDEX idx_folder_parent_id ON folder(parent_id);

-- ============================================
-- 4. 笔记表
-- ============================================
CREATE TABLE note (
    id            BIGSERIAL PRIMARY KEY,
    user_id       BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    notebook_id   BIGINT NOT NULL REFERENCES notebook(id) ON DELETE CASCADE,
    folder_id     BIGINT REFERENCES folder(id) ON DELETE SET NULL,
    title         VARCHAR(500) NOT NULL DEFAULT '未命名笔记',
    content_md    TEXT,
    content_html  TEXT,
    word_count    INTEGER DEFAULT 0,
    is_pinned     BOOLEAN DEFAULT FALSE,
    created_at    TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at    TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    is_deleted    BOOLEAN DEFAULT FALSE
);
CREATE INDEX idx_note_user_id ON note(user_id);
CREATE INDEX idx_note_notebook_id ON note(notebook_id);
CREATE INDEX idx_note_folder_id ON note(folder_id);
CREATE INDEX idx_note_updated_at ON note(updated_at DESC);
CREATE INDEX idx_note_is_deleted ON note(is_deleted);

-- ============================================
-- 5. 笔记链接表（双向链接 / 知识图谱）
-- ============================================
CREATE TABLE note_link (
    id              BIGSERIAL PRIMARY KEY,
    source_note_id  BIGINT NOT NULL REFERENCES note(id) ON DELETE CASCADE,
    target_note_id  BIGINT NOT NULL REFERENCES note(id) ON DELETE CASCADE,
    link_type       VARCHAR(20) DEFAULT 'wikilink',
    created_at      TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(source_note_id, target_note_id)
);
CREATE INDEX idx_note_link_source ON note_link(source_note_id);
CREATE INDEX idx_note_link_target ON note_link(target_note_id);

-- ============================================
-- 5. 知识库表
-- ============================================
CREATE TABLE knowledge_base (
    id          BIGSERIAL PRIMARY KEY,
    user_id     BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    name        VARCHAR(255) NOT NULL,
    description VARCHAR(1000),
    icon        VARCHAR(50) DEFAULT '📚',
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_knowledge_base_user_id ON knowledge_base(user_id);

-- ============================================
-- 6. 导入文档表
-- ============================================
CREATE TABLE document_source (
    id                BIGSERIAL PRIMARY KEY,
    knowledge_base_id BIGINT NOT NULL REFERENCES knowledge_base(id) ON DELETE CASCADE,
    note_id           BIGINT REFERENCES note(id) ON DELETE SET NULL,
    user_id           BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    file_name         VARCHAR(500) NOT NULL,
    file_type         VARCHAR(20) NOT NULL,
    file_size         BIGINT NOT NULL,
    storage_path      VARCHAR(1000),
    raw_content       TEXT,
    chunk_status      VARCHAR(20) DEFAULT 'pending',
    error_message     TEXT,
    imported_at       TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_document_knowledge_base ON document_source(knowledge_base_id);
CREATE INDEX idx_document_user_id ON document_source(user_id);
CREATE INDEX idx_document_note_id ON document_source(note_id);
CREATE INDEX idx_document_chunk_status ON document_source(chunk_status);

-- ============================================
-- 7. 知识块表（含向量）
-- ============================================
CREATE TABLE knowledge_chunk (
    id                BIGSERIAL PRIMARY KEY,
    document_id       BIGINT REFERENCES document_source(id) ON DELETE CASCADE,
    knowledge_base_id BIGINT NOT NULL REFERENCES knowledge_base(id) ON DELETE CASCADE,
    note_id           BIGINT REFERENCES note(id) ON DELETE CASCADE,
    chunk_index       INTEGER NOT NULL,
    chunk_content     TEXT NOT NULL,
    chunk_token_count INTEGER DEFAULT 0,
    embedding         VECTOR(1024),
    source_info       JSONB,
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_chunk_document_id ON knowledge_chunk(document_id);
CREATE INDEX idx_chunk_knowledge_base ON knowledge_chunk(knowledge_base_id);
CREATE INDEX idx_chunk_note_id ON knowledge_chunk(note_id);
CREATE INDEX idx_chunk_embedding ON knowledge_chunk USING ivfflat (embedding vector_cosine_ops);

-- ============================================
-- 8. AI 供应商配置表
-- ============================================
CREATE TABLE ai_config (
    id                BIGSERIAL PRIMARY KEY,
    user_id           BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    provider_name     VARCHAR(50) NOT NULL,
    display_name      VARCHAR(100),
    api_key           TEXT NOT NULL,
    api_base_url      VARCHAR(500),
    chat_model        VARCHAR(100) NOT NULL,
    embedding_model   VARCHAR(100),
    is_active         BOOLEAN DEFAULT FALSE,
    sort_order        INTEGER DEFAULT 0,
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(user_id, provider_name)
);
CREATE INDEX idx_ai_config_user_id ON ai_config(user_id);

-- ============================================
-- 9. 对话表
-- ============================================
CREATE TABLE conversation (
    id                BIGSERIAL PRIMARY KEY,
    user_id           BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    title             VARCHAR(500),
    knowledge_base_id BIGINT REFERENCES knowledge_base(id) ON DELETE SET NULL,
    provider_name     VARCHAR(50),
    model             VARCHAR(100),
    mode              VARCHAR(20) DEFAULT 'chat',
    is_favorite       BOOLEAN DEFAULT FALSE,
    message_count     INTEGER DEFAULT 0,
    token_usage       INTEGER DEFAULT 0,
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_conversation_user_id ON conversation(user_id);
CREATE INDEX idx_conversation_favorite ON conversation(is_favorite);
CREATE INDEX idx_conversation_updated_at ON conversation(updated_at DESC);

-- ============================================
-- 10. 消息表
-- ============================================
CREATE TABLE message (
    id                BIGSERIAL PRIMARY KEY,
    conversation_id   BIGINT NOT NULL REFERENCES conversation(id) ON DELETE CASCADE,
    role              VARCHAR(20) NOT NULL,
    content           TEXT NOT NULL,
    tokens            INTEGER DEFAULT 0,
    metadata          JSONB,
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_message_conversation_id ON message(conversation_id);
CREATE INDEX idx_message_created_at ON message(conversation_id, created_at);

-- ============================================
-- 11. Prompt 快捷指令表
-- ============================================
CREATE TABLE prompt_shortcut (
    id            BIGSERIAL PRIMARY KEY,
    user_id       BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    name          VARCHAR(100) NOT NULL,
    prompt        TEXT NOT NULL,
    description   VARCHAR(500),
    is_preset     BOOLEAN DEFAULT FALSE,
    sort_order    INTEGER DEFAULT 0,
    is_enabled    BOOLEAN DEFAULT TRUE,
    created_at    TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at    TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_prompt_shortcut_user_id ON prompt_shortcut(user_id);
CREATE INDEX idx_prompt_shortcut_enabled ON prompt_shortcut(is_enabled);

-- ============================================
-- 12. 用户画像表
-- ============================================
CREATE TABLE user_profile (
    id                BIGSERIAL PRIMARY KEY,
    user_id           BIGINT NOT NULL REFERENCES note_user(id) ON DELETE CASCADE,
    identity          VARCHAR(500),
    tech_stack        VARCHAR(1000),
    answer_preference VARCHAR(1000),
    custom_prompt     TEXT,
    is_enabled        BOOLEAN DEFAULT TRUE,
    created_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at        TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_user_profile_user_id ON user_profile(user_id);

-- ============================================
-- 13. 系统配置表
-- ============================================
CREATE TABLE system_config (
    id              BIGSERIAL PRIMARY KEY,
    config_key      VARCHAR(100) NOT NULL UNIQUE,
    config_value    TEXT NOT NULL,
    description     VARCHAR(500),
    created_at      TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at      TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 6. 索引策略总结

| 表 | 索引 | 目的 |
|----|------|------|
| `note_user` | `username` | 用户登录查询 |
| `folder` | `user_id`, `notebook_id`, `parent_id` | 按用户/仓库查询、查询子目录 |
| `note` | `user_id`, `notebook_id`, `folder_id`, `updated_at`, `is_deleted` | 按用户/仓库/目录筛选、排序、软删除过滤 |
| `note_link` | `source_note_id`, `target_note_id` | 知识图谱双向查询 |
| `knowledge_base` | `user_id` | 按用户查询知识库 |
| `document_source` | `knowledge_base_id`, `note_id`, `chunk_status` | 按知识库/笔记查询、处理状态查询 |
| `knowledge_chunk` | `document_id`, `knowledge_base_id`, `note_id`, `embedding` (IVFFlat) | 按维度查询、向量相似度检索 |
| `ai_config` | `user_id`, `(user_id, provider_name)` | 按用户查询配置、唯一性约束 |
| `conversation` | `user_id`, `is_favorite`, `updated_at` | 按用户查询、收藏筛选、对话列表排序 |
| `message` | `(conversation_id, created_at)` | 按对话查询消息、按时间排序 |
| `prompt_shortcut` | `user_id`, `is_enabled` | 按用户查询、查询启用的快捷指令 |
| `user_profile` | `user_id` | 按用户查询画像 |

```bash
docker run -d \
  --name nm-postgres \
  -e POSTGRES_DB=notemind \
  -e POSTGRES_USER=nm_user \
  -e POSTGRES_PASSWORD=nm_pass \
  -p 5432:5432 \
```

```bash
# 备份
pg_dump -U nm_user -d notemind > backup_$(date +%Y%m%d).sql

# 恢复
psql -U nm_user -d notemind < backup.sql
```
