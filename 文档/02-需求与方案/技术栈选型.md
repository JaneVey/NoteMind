# NoteMind 技术栈选型

> 各技术组件的选型理由与说明。详见 [[方案定位]]

## 一、前端

| 组件 | 选型 | 说明 |
|------|------|------|
| 框架 | **Vue 3** + **TypeScript** + **Vite** | Composition API，TS 推荐 |
| UI 库 | **shadcn-vue**（基于 **Radix Vue** + **Tailwind CSS**） | 现代无样式组件库，完全可定制；替代原 Element Plus |
| 原子化 CSS | **Tailwind CSS 3.x** | 配合 shadcn-vue 使用，按需生成，代码体积小 |
| 状态管理 | **Pinia** | 已掌握 |
| 路由 | **Vue Router** | |
| Markdown 编辑器 | **Vditor**（首选） | 所见即所得 + 即时渲染双模式；备选 Milkdown / Editor.js |
| Markdown 渲染 | **markdown-it** | 笔记展示 / 消息渲染 |
| 图谱可视化 | **vis-network**（首选） | 备选 D3.js / ECharts |
| 网络请求 | **Axios** | |
| SSE 接收 | **EventSource + fetch** | AI 流式输出 |
| 图标 | **lucide-vue-next** | 统一图标风格 |

### TypeScript 推荐理由
- 提升代码质量和可维护性
- 配合 Vditor 等库的 TS 类型支持
- 对毕设论文有加分（体现工程规范）

---

## 二、后端

| 组件 | 选型 | 说明 |
|------|------|------|
| 语言 | **Java 17** | LTS 版本 |
| 框架 | **Spring Boot 3.x** | 最新稳定版 |
| AI 框架 | **Spring AI** | LLM 调用、Embedding、Prompt 管理、RAG 编排、VectorStore 集成 |
| ORM | **MyBatis-Plus** | 熟悉，减少 SQL 编写 |
| 安全 | **Spring Security + JWT** | 用户认证、接口鉴权、BCrypt 密码加密 |
| 实时通信 | **SSE** | AI 流式输出（比 WebSocket 更轻量） |

### 设计原则：用户与业务解耦

- **auth 包**负责登录、注册、JWT 签发
- **framework 包**负责 Security 配置、Filter 链
- 业务模块（note / knowledge / ai）**只通过 Controller 传入的 `userId`** 关联用户
- 业务层不感知 JWT、Security 上下文

---

## 三、数据库

| 类型 | 选型 | 用途 |
|------|------|------|
| 关系型 | **PostgreSQL** | 业务数据存储（AI 项目生态好，原生支持向量） |
| 向量数据库 | **pgvector** | 文档 / 笔记向量存储、Embedding 结果、相似度检索 |
| 缓存 | **Redis 7.x** | Token、Session、AI 聊天上下文、热点数据 |

### pgvector 优势
- 无需额外部署 Milvus / Pinecone 等独立向量库
- PostgreSQL 原生扩展，数据一致性有保障
- 适合 MVP 阶段的数据规模

> Milvus 作为未来数据规模扩大后的备选。

---

## 四、文件存储

| 组件 | 用途 |
|------|------|
| **MinIO** | PDF、Word、PPT、图片、Markdown 附件存储 |

**流程**：用户上传 → MinIO 存储 → 数据库保存文件信息

> S3 兼容接口，与文档处理流程解耦，方便后续迁移 / 备份。

---

## 五、AI 能力

### 大语言模型（LLM）

通过 API 调用，用户自备 API Key：

| 供应商 | 对话模型 | 向量模型 | 优先级 |
|--------|---------|---------|--------|
| **DeepSeek** | `deepseek-chat` | `deepseek-embedding` | 🥇 主要使用 |
| **OpenAI** | `gpt-4o` | `text-embedding-3-small` | 🥈 备选 |
| **Gemini** | `gemini-2.0-flash` | `text-embedding-004` | 🥉 Google 免费额度高 |
| Claude | 已移除 | 无原生 Embedding | ❌ |

> 重构后移除 Claude，原因：API 格式不兼容、无原生 Embedding、Gemini 对学生更友好。

### Embedding 模型备选

除供应商自带外，也可对接：
- **BGE**（BAAI/bge-m3）— 开源，可本地部署
- **Jina Embedding** — 高性能，支持长文本

### 文档解析

| 方式 | 用途 |
|------|------|
| **Apache Tika** | PDF / Word / PPT 结构解析 |
| **OCR API** 或 **Tesseract** | 图片文字识别（P1 阶段） |
| **LLM 辅助** | AI 增强内容组织（导入时可选） |

---

## 六、RAG 完整链路

```
用户上传文档
    ↓
MinIO 存储
    ↓
文档解析（Apache Tika / OCR）
    ↓
文本清洗
    ↓
文本切片（按段落/标题，设定块大小 + 重叠）
    ↓
Embedding（调用供应商 API）
    ↓
pgvector 存储
    ↓
用户提问
    ↓
语义检索（向量相似度）
    ↓
拼接上下文 + 引用标注
    ↓
LLM 生成回答
    ↓
返回答案 + 引用来源
```

## 七、部署方案

### MVP 版（Docker Compose）

```
Frontend (Vue3)     →  静态资源打包到后端
Backend (Spring Boot)
PostgreSQL + pgvector
Redis
MinIO
Nginx（反向代理，可选）
```

### 环境

- 服务器：**Linux**
- 容器：**Docker** + **Docker Compose**
- Web 服务器：**Nginx**（代理前端静态资源 + 后端 API）
