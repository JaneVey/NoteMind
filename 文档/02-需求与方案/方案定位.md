# NoteMind 方案定位

> 毕设方向讨论的最终结论，来自 [[毕设重构讨论结果.md]]

## 一句话定位

> 一个融合 Obsidian 知识管理能力与 RAG 文档智能能力的 AI 知识管理平台。

**核心理念**：

| 角色 | 职责 |
|------|------|
| 笔记 | 知识创造和沉淀 |
| 知识库 | 知识理解和检索 |
| AI | 辅助整理、分析、生成 |

**论文课题名称**：基于 RAG 的 NoteMind 智能知识管理平台设计与实现

---

## 模块划分

```
系统
├── AI助手      — 通用 AI 对话入口（类似 ChatGPT 首页）
├── 笔记        — 多仓库 Markdown 笔记 + 三栏布局 + AI 辅助
├── 知识库      — 文档上传 → RAG 智能问答 + 引用溯源
└── 设置        — AI 模型管理 + Prompt 快捷指令 + 系统配置
```

---

## 模块一：AI 助手

**定位**：不依赖笔记、不依赖知识库的通用 AI 对话。

### 功能

| 功能 | 说明 |
|------|------|
| 新建对话 | 创建 AI 会话 |
| 历史管理 | 查看、重命名、删除、收藏 |
| 知识库绑定 | 可选，某个聊天可绑定知识库，默认用该库 RAG |
| 用户画像 / AI 记忆 | 用户主动维护（身份、方向、偏好），注入 System Prompt |

### 数据库

`conversation` → `message`

---

## 模块二：笔记系统

**定位**：Web 版 Obsidian，核心是 Markdown 知识创作。

### 多仓库设计

```
笔记
├── Java 仓库
├── 毕设仓库
└── 秋招仓库
```

### 三栏布局

```
┌──────────┬─────────────────┬──────────────┐
│ 仓库/目录树 │  Markdown 编辑器  │  AI 助手窗口  │
└──────────┴─────────────────┴──────────────┘
```

### 功能列表

| 分类 | 功能 |
|------|------|
| 基础 | 新建/删除/重命名、文件夹管理、Markdown 编辑、图片插入、代码块、搜索 |
| 进阶 | 导出 PDF、源码模式、阅读模式、历史版本（P1） |
| AI 辅助 | 当前笔记对话、选中文字操作（解释/总结/润色等）、AI 直接修改笔记 |
| 文件导入 | PDF/Word/图片 → Markdown（普通转换或 AI 增强转换） |
| 知识图谱 | 双向链接 `[[note]]`，仓库级图谱，AI 自动分析关联（未来增强） |

### 笔记 → 知识库

单向联动：选择文件夹 → 点击"加入知识库" → 生成 RAG 数据。

---

## 模块三：知识库系统

**定位**：类似 ima 个人知识库，上传资料 → RAG → 智能问答。

### 结构

```
知识库
├── Java 知识库
├── 毕设资料库
└── 论文库
```

### 支持格式

Markdown、PDF、Word、PPT、图片

### 文档处理流程

```
上传 → MinIO → 结构解析 → OCR → 文本切片 → Embedding → pgvector → 完成
```

### 文档详情页

显示：名称、类型、大小、上传/更新时间、解析状态
操作：预览、删除、重新解析

### RAG 问答

- 区别笔记：笔记针对单篇，知识库针对整个库
- **引用溯源**（重要）：回答标注引用文档章节，支持点击查看来源

---

## 模块四：设置

| 分类 | 内容 |
|------|------|
| 基础设置 | 主题、字体大小、编辑器设置 |
| AI 模型管理 | DeepSeek / OpenAI / Gemini，API Key 配置，默认模型 |
| AI 参数 | Temperature、Max Tokens、Prompt 模板 |
| Prompt 快捷指令 | 🎯 重点功能。用户自定义指令，集成到编辑器右键菜单 |

### Prompt 快捷指令示例

```
名称: 论文降重
Prompt: 请降低以下内容的 AI 生成痕迹...
```

选中文字 → 右键 → "论文降重" → AI 处理

| 功能 | 状态 |
|------|------|
| 注册 / 登录 | ✅ |
| Spring Security + JWT | ✅ |
| 修改密码 | ✅ |
| 修改个人信息 | ✅ |
| 忘记密码 | ⚠️ 可选 |
| 邮箱验证 / OAuth | ❌ |

数据库所有业务表通过 `user_id` 关联用户。详见 [[用户系统设计]]

## 核心技术路线

| 层 | 选型 |
|----|------|
| 后端 | Spring Boot 3 + Spring AI + Spring Security + JWT |
| 数据库 | PostgreSQL + pgvector |
| 缓存 | Redis |
| 存储 | MinIO |
| AI | LLM API + Embedding API + 结构解析 API + OCR |
| 前端 | Vue 3 + TypeScript + Tailwind CSS + shadcn-vue |

详见 [[技术栈选型]]

## 暂不包含

- ❌ 共享知识库
- ❌ 多人协作
- ❌ Spring Cloud 微服务
- ❌ RabbitMQ
- ❌ AI Agent 自动执行
- ❌ 插件系统 / MCP

> 属于未来产品化方向。

---

## 核心创新点

1. 笔记系统 + RAG 知识库融合
2. 用户可配置 AI 能力（Prompt 快捷指令）
3. Obsidian 双链知识图谱
4. AI 辅助知识整理（三种写作辅助形式）
5. 文档智能解析和问答
